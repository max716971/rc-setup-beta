# RC SETUP

Application web locale pour gérer tes voitures, pistes et réglages de radio commandé.

## Fonctionnalités
- Gestion des voitures
- Gestion des pistes
- Enregistrement des setups
- Stockage local avec localStorage
- Export / import JSON
- Compatible installation sur iPhone via Safari (écran d’accueil)
- Fonctionne hors ligne via un service worker

## Utilisation
1. Ouvre `index.html` dans un navigateur, ou publie le dossier sur GitHub Pages / Netlify / Vercel.
2. Ajoute tes voitures et pistes.
3. Crée des setups avec conditions, pneus et suspension.
4. Exporte régulièrement une sauvegarde JSON.

## Installation iPhone
1. Ouvre la page dans Safari.
2. Appuie sur le bouton Partager.
3. Choisis "Sur l’écran d’accueil".
4. Valide pour créer l’icône.

## Déploiement
Tu peux publier ce dossier sur GitHub Pages ou un hébergement statique. Pour GitHub Pages, active Pages sur le dépôt et sélectionne la branche `main` / dossier racine.
